Widget demo page

This page stands in for a client's website. The chat launcher in the bottom-right corner is loaded by the same one-line snippet a client pastes into their site:

<script src="http://localhost:8000/widget.js" data-key="__WIDGET_KEY__" async></script>

Replace the host with the deployed server's address when embedding on a real site, and add that site to the client's allowed_origins.
